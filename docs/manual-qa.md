# Manual QA matrix

Complete the applicable rows for every verified screen and attach sanitized evidence.

| Area | Required checks |
|---|---|
| Devices | iPhone 17e, iPhone 17 Pro, iPhone 17 Pro Max; iOS 27; portrait |
| Appearance | Light, Dark, Increased Contrast, Bold Text |
| Text | Default through accessibility Dynamic Type; long English; pseudo-localization; RTL layout |
| Assistive technology | Accessibility Inspector, VoiceOver order/actions, Voice Control names, keyboard/focus where relevant |
| Motion | Reduce Motion; interrupt actions during transitions; no feedback conveyed only by motion/haptic |
| State | Populated, empty, loading, offline, error, permission, disabled, destructive, recovery |
| Input | Software keyboard, dictation where relevant, paste safety, multiline, dismissal, focus restoration |
| System integration | Live and simulated behavior; denial and Settings recovery; simulator limitations documented |
| Performance | Launch, scrolling, typing, search, large timelines, media grids; no reproducible hitch or blocked input |
| Privacy | Only fictional data; no keys in logs, screenshots, errors, clipboard residue, or accessibility values |

Physical-device acceptance is required for camera/scanner, photos/files, microphone, notifications, sharing, keyboard behavior, haptics, and perceived performance.
