# Screen contract: New Chat

- ScreenID: `chats.new-direct`
- Status: `draft`
- Audience: product
- Approvals: user pending; independent review pending

## Proposed scope

Search People by human-facing profile information, show deterministic results and groups in common, and start a simulated direct Chat. Cover initial, no-results, loading, invalid query, unavailable person, error and keyboard states.

## Gate

Resolve search scope, result hierarchy, exact copy, Apple citations and focused comparisons. Do not implement.
